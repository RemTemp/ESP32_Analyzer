# ESP32 Signal Analyzer

Недорогой анализатор сигналов на **ESP32** с веб-интерфейсом:  
осциллограф (6 аналоговых каналов), логический анализатор (8 цифровых), FFT, сохранение на внешнюю Flash и выгрузка CSV.

Работает как точка доступа Wi‑Fi — телефон или ноутбук подключаются напрямую, браузер открывает прибор.

---

## Возможности

| Функция | Описание |
|--------|----------|
| **Осциллограф** | 6 каналов АЦП, 0…3.3 В, 12 бит |
| **Логический анализатор** | 8 цифровых входов 0/1 |
| **Триггер** | По аналоговому или цифровому каналу, фронт ↑ / ↓ |
| **Окно захвата** | От «максимально быстро» до 10…500 мс |
| **FFT / спектр** | Спектр по выбранному аналоговому каналу |
| **Live** | Автоповтор захвата |
| **Память** | До 24 файлов на W25Q32 (4 МБ) |
| **CSV** | Скачивание для Excel / Python (разделитель `;`) |
| **Калибровка** | Offset и scale для перевода в вольты |

---

## Что нужно

### Железо

- Плата **ESP32** (WROOM-32 / DevKit)
- Микросхема **Winbond W25Q32** (SPI NOR Flash, 4 МБ)
- Провода, макетная плата
- Желательно: конденсаторы **100 нФ** с каждого аналогового входа на GND

### Софт

- [Arduino IDE](https://www.arduino.cc/en/software) или PlatformIO  
- Поддержка плат **esp32** by Espressif (Board Manager)

Дополнительные библиотеки **не требуются** — только стандартные `WiFi`, `WebServer`, `SPI`.

## Подключение

### W25Q32 → ESP32

| Ножка W25Q32 | Сигнал | ESP32 |
|--------------|--------|-------|
| 1 | /CS | GPIO **5** |
| 2 | DO (MISO) | GPIO **19** |
| 3 | /WP | **3.3 V** |
| 4 | GND | GND |
| 5 | DI (MOSI) | GPIO **23** |
| 6 | CLK | GPIO **18** |
| 7 | /HOLD | **3.3 V** |
| 8 | VCC | **3.3 V** |

> /WP и /HOLD обязательно на 3.3 V, иначе запись на Flash не пойдёт.

### Аналоговые входы (ADC1, совместимы с Wi‑Fi)

| Канал | GPIO |
|--------|------|
| A0 | 36 |
| A1 | 39 |
| A2 | 34 |
| A3 | 35 |
| A4 | 32 |
| A5 | 33 |

**Только 0…3.3 В.** Более высокое напряжение — только через делитель.  
Рекомендуется 100 нФ между входом и GND у каждого используемого канала.

### Цифровые входы (INPUT_PULLDOWN)

| Канал | GPIO |
|--------|------|
| D0 | 13 |
| D1 | 14 |
| D2 | 15 |
| D3 | 16 |
| D4 | 17 |
| D5 | 21 |
| D6 | 22 |
| D7 | 25 |

Уровень: 0 В = «0», 3.3 В = «1».

## Быстрый старт

1. Открой папку `ESP32_Analyzer` в Arduino IDE (файл `ESP32_Analyzer.ino`).
2. Выбери плату **ESP32 Dev Module**, порт, загрузи скетч.
3. Открой Serial Monitor на **115200** — должно быть примерно:

```text
=== ESP32 Analyzer ===
softAP(ESP32-Analyzer): OK
IP: 192.168.4.1
W25Q32 OK
ADC ready
http://192.168.4.1
```

4. Подключись к Wi‑Fi:
   - **SSID:** `ESP32-Analyzer`
   - **Пароль:** `12345678`
5. В браузере открой: **http://192.168.4.1**

## Как пользоваться

### Слева — основной прибор

- **Захватить** — один снимок всех включённых каналов  
- **Сохранить** — записать снимок в файл на W25Q32 (`S001`, `S002`, …)  
- **Live** — повторять захват примерно раз в 1.5 с  
- **Окно** — длительность кадра (10…500 мс или «макс. быстро»)  
- **Триггер** — канал и уровень, по которому ждать фронт  
- Вкладки **Осциллограф** / **Спектр**  
- Галочки каналов (колонка по центру) — что реально опрашивать  

### Справа — сохранённые файлы

- Клик по имени — развернуть график под файлом (можно несколько)  
- **↓** — скачать **CSV**  
- **✕** — удалить файл  
- При почти полной памяти показывается предупреждение  

### Калибровка

Внизу слева: `offset` и `scale`, кнопка «Применить к A0–A5».

```text
V = (raw - offset) × scale
```

По умолчанию: `offset = 0`, `scale ≈ 3.3/4095 ≈ 0.000805` В/отсчёт.

В CSV есть и сырые значения (`A0_raw`), и вольты (`A0_V`).

## Формат файлов

### На Flash (бинарный CAP4)

Компактная запись для прибора:

1. Заголовок 16 байт (`CAP4`, время, число точек, каналы)  
2. Аналоговые данные: `uint16` по каналам  
3. Цифровые: `0/1` по каналам  

До **24** файлов, имена `S001`…  

### CSV (для компьютера)

Разделитель **`;`** (удобно для Excel с русской локалью):

```text
t_ms;A0_raw;A1_raw;...;A0_V;A1_V;...;D0;D1;...
0.000;2048;2100;...;1.6500;1.6915;...;0;1;...
```

Открыть в Excel / LibreOffice / Python (`pandas.read_csv(..., sep=';')`).

## Ограничения (важно)

1. **Частота дискретизации** невысокая (порядок единиц кГц), это не лабораторный осциллограф.  
2. **АЦП ESP32** шумный; без калибровки «вольты» ориентировочные.  
3. Вход **только 0…3.3 В** — иначе можно повредить чип.  
4. При Wi‑Fi и частом опросе ESP32 **нагревается** — нормально; выключай лишние каналы и Live, если не нужны.  
5. Неиспользуемые аналоговые входы лучше не оставлять «в воздухе» (подтяжка/конденсатор).  
6. Точка доступа рассчитана на локальную работу рядом с прибором.

## Типичные проблемы

| Симптом | Что проверить |
|--------|----------------|
| Нет сети `ESP32-Analyzer` | Serial: есть ли `softAP: OK`? Питание 5 В стабильное? |
| `W25Q32 FAIL` | Распиновка, /WP и /HOLD на 3.3 V, общий GND |
| Запись Flash не работает | Снова /WP, /HOLD; JEDEC ID должен быть `0xEF4016` |
| Наводки между каналами | 100 нФ на входах; отключить неиспользуемые каналы |
| CSV «всё в одном столбце» | Импорт с разделителем `;` |
| Сильный нагрев | Снять Live, отключить лишние каналы, не жать «Захватить» подряд |

## API (кратко)

| URL | Назначение |
|-----|------------|
| `GET /` | Веб-интерфейс |
| `GET /capture` | Захват → JSON |
| `GET /save` | Сохранить текущий захват |
| `GET /files` | Список файлов |
| `GET /file?id=N` | Данные файла (JSON) |
| `GET /csv?id=N` | Скачать CSV |
| `GET /delete?id=N` | Удалить файл |
| `GET /window?ms=50` | Длительность окна |
| `GET /cal?off=0&scale=0.0008` | Калибровка |
